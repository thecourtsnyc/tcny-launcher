# The Courts NYC Launcher

Official launcher for **The Courts NYC**. Use it to join the server.

## Download

Get the latest `TCNYLAUNCHER.exe` from the [Releases page](../../releases/latest).

1. Download `TCNYLAUNCHER.exe` (you can ignore `version.json`).
2. Run it and press **PLAY**.
3. Keep the launcher open while you play.

The launcher updates itself automatically when a new version is released.

## Anti-cheat

While it is open, the launcher checks for cheat tools and screen overlays, and keeps a short screen capture in memory. The capture is only sent to staff if a cheat or overlay is detected.

## Windows SmartScreen / antivirus warnings

The launcher is not code-signed yet, so Windows or some antivirus tools may show a warning. If you downloaded it from this page, click **More info** then **Run anyway**.
